# 50 页讲座的 IP 配图位置建议

这是**未来整套讲座的配图建议**，依据现有 `slides.json` 的 50 页顺序和原讲稿整理。不是已完成的配图清单，也不表示 50 页网页幻灯片已经全部完成。

目前只安排了两张场景样图，处于已生成／正在生成阶段：

1. 把学习笔记折成能浮在水面的纸船：**学到的 → 做出来**。
2. 拿 AI 给出的答案钥匙测试真实锁芯：**答案 → 验证**。

本次仅提出位置与叙事建议，没有生成新图，没有修改 `slides.json` 或原讲稿，也没有检查两张样图的最终文件与画面。因此不将任一张标为“验收完成”。

## 两张现有样图的使用边界

- **纸船优先用在第 16 页。** 第 48 页“最重要的，仍然是你自己的想法”也能呼应这个意象；如需要，可用同一场景的小范围回看，不必再生成一张近似图，也不把它作为第二个全幅插画页面。
- **钥匙测试优先用在第 33 页。** 第 34 页应保留“操作步骤 / 实际结果 / 预期结果”的清晰结构，用具体语言完成从隐喻到操作的过渡。
- 两张都是概念隐喻。纸船不是讲者声称做过的真实产品；钥匙也不代表 AI 的答案必然正确或必然错误。画面只强调行动与验证。

## 节奏与版面建议

- 以 **6 个叙事节点**为上限候选，不平均分配到每页。现阶段只需先把两张样图与第 16、33 页配合好，其他四张等整套风格确认后再决定。
- IP 要有明确目标、对象和结果：折船、整理方法、解释步骤、体贴交接、测试锁芯、收集反馈。避免每页重复站在角落指标题、竖拇指或举灯泡。
- 有真实案例或教学结构的页面继续使用原本素材：第 3 页项目入口、第 9 页网站案例、第 18 页封面案例、第 21 页内存示意、第 38—40 页 Builder 结构、资源与二维码页面。无需用 IP 抢占它们的阅读空间。
- 插画页可以让场景占主要区域，旁边只保留一个结论或最多两个短标签。第 19 页有两个教程入口，二维码宜留在固定角落或放进资源抽屉，不压在插画动作上。
- 中文标题、关键短句与箭头由网页排版承担；画面内不强求生成大段中文。IP 形象、服装、线条和主色始终沿用已选参考，角色通过动作变化，不靠换造型区分页码。
