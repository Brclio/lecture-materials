# 厦门工学院｜AI 浪潮下，我们该怎么学？

双击同目录的 **index.html** 开始。换电脑时，把整个放映包解压到一个文件夹再打开；图片、字体、二维码、小实验都在本地，不用启动服务。访问二维码中的网站需要联网。

## 上台

- 用 Chrome 或 Edge 打开主文件，按 **F** 全屏，按 **← / →** 或翻页笔翻页。**O** 打开目录，**?** 查看操作，手机可左右滑动。
- 要看逐页提示，把电脑与投影设为**扩展显示**。按 **P** 打开讲者窗口，留在自己屏幕；把主放映窗口拖到投影，再全屏。双屏会一起翻页。镜像投影时只使用主放映窗口。
- 点击原稿案例图可单独投影，点 **放大细看** 检查文字，按 **Esc** 返回当前幻灯片。
- 第 **13** 页可直接输入现场给出的活动名，点「预览新文件名」。也可用空名称测试提示。光标留在输入框里时，先按 **Esc** 结束输入，再按方向键翻页。
- 第 **20–21** 页的油饼故事、第 **27–28** 页的 Builder 判断都是先问再揭晓。不要提前翻出答案。
- 第 **33** 页展示联系码，第 **34** 页进入问答，可扫码读线上讲稿。点分项资料链接打开 **resources.html**，每个二维码都可以单独投影。
- 现场电脑不便开 HTML 时，用 **厦门讲座·投影备用.pdf**。PDF 每页只含投影内容；第 13 页展示示例结果，不支持输入。

## 改稿

直接编辑 **index.html**。每个 `<section class="slide …">` 对应一页；`<div class="inner">` 是观众看到的内容，`<aside class="notes">` 是该页的讲者提示。修改页面标题时同时更新 `data-title`，讲者窗和目录会使用它。页面顺序就是文件内的顺序。

版式在 **assets/slides.css**，播放控制在 **assets/deck.js**，小实验在 **assets/demo.js**。案例图保留了 [素材出处](assets/evidence/sources.md)，四张原创插画附有[封面与验证插画提示词](assets/xiamen-talk-illustrations/prompts.md)及[油饼摊漫画提示词](assets/xiamen-talk-illustrations/pancake-prompts.md)。可独立阅读的讲者提示见 **逐页讲者手卡.md**。
