AI 时代，电脑如何选？

先说答案学习、做网站、写代码和内容创作，预算允许，我优先推荐苹果芯片的 Mac。

?

接下来讲三个理由：Memory、Workflow、Mobility。再讲哪些人不建议选 Mac。

为什么推荐 Mac

三个理由：装得下、少折腾、带得走

Memory内存与显存合一
本地跑大模型，先看装不装得下。统一内存让 GPU 能用上更大的空间。
Workflow命令行，AI 直接执行
类 Unix 系统，Codex 不用装 WSL。
Windows 装软件下载安装包 → 下一步 → 选路径 → 下一步…… AI 要看屏幕、找按钮
Mac 装软件$ brew install ollama
AI 一行命令就执行完
Mobility续航与便携
不插电也有不错的性能：宿舍写代码、图书馆做项目、没网也能跑本地 AI。

重点讲 Workflow：AI 是直接执行命令行方便，还是实时看你的 Windows 界面、定位、点击方便？更别说速度和 token 消耗。Windows 也能做到，但零基础同学要在环境配置上花大量时间。已经有 Windows 电脑的同学，先用现有设备开始就好。

Memory · 本地跑大模型

32 GB 内存 ＋ 8 GB 显存 ≠ 40 GB

常见独显电脑

显存不够，一部分模型只能放到系统内存，往往会拖慢速度。

苹果芯片的 Mac

大内存机型上，一些普通显卡装不下的模型有机会跑起来。

装得下，不代表跑得更快——但至少给了你更多尝试的可能。

很多 Windows 电脑内存和显存是分开的，即使有 64GB 内存，显卡可能只有 8、16GB。图里的数字是示意。速度还取决于芯片、模型、精度和软件。

说清楚边界

这四类人，不建议盲目选 Mac

主要打游戏

Windows 的游戏兼容性通常更好。

专业软件只认 Win

优先满足你的专业需求。

大规模模型训练

NVIDIA 显卡的 CUDA 生态更成熟，硬件也好扩展。

预算有限

同样的预算，Windows 有更多配置可选。

电脑性能不是生产力的全部。减少折腾、降低开始做一件事的门槛，同样是生产力。

对我而言，Mac 的价值不只是性能有多强，而是突然有个想法时，可以更快借助 AI 把它实现出来。

“
工具是用来创造的，
不是用来折腾的。

冯仑讲的油饼故事

一张油饼，
多赚两毛钱？

算一笔账

卖 2 元，成本 5 角。若压到 3 角，一张能多赚 2 角。

换一种做法

另一位摊主用好油、好面，把心思放在客人吃到的饼上。

客人记住了什么

热饼包上纸，提醒一句「小心烫」。愿意再来的人多了。

原故事借两位摊主说明长期主义：一种做法不断压缩成本，另一种做法在油、面和不烫手的包装上给客人留下价值。讲完可以问：我们的文章、教程和产品里，哪件小事相当于那张包饼的纸？

两位摊主，两条路

路是自己一块砖、一片瓦铺出来的

眼前利益

  • 拼命压榨「价值空间」
  • 一时赚得盆满钵满
  • 未来路越走越窄

长期主义

  • 拼命退让「价值空间」，留给对方
  • 一时利润不尽人意
  • 未来路越走越宽

有钱当然更顺，但没钱，也可以把自己的帝国铺好。

注重眼前利益的人，一点价值空间都不想留给对方；注重长期主义的人，想把价值空间最大化留给对方。路不是靠别人，也不是纯靠钱。

  2. 第二步AI 时代 · 变简单 把它做出来

    让 AI 帮你做第一版，自己把最重要的功能走一遍。

  3. 第三步AI 时代 · 更难 把它推广出去

以前说 Builder，容易只想到开发者。现在有了 Coding Agent，不同专业的人也能做东西。让大家用自己的小项目逐项对应：用户是谁，能让他试的版本是什么，你怎样让他知道它存在。

这三件事，在 AI 时代有什么变化？

做出来变简单了，另外两步更难了
